# 远程任务

聊天大脑负责“对话”；远程任务负责“把一件长活干完”。任务跑在另一个受控 Agent 进程里，你可以在微信里回它、让它继续，或者结束它。

## 派发

```bash
wemind task "把 docs 里的接入方案整理成一页说明" --cwd /path/to/project
wemind task --agent codex "跑一遍测试并总结失败项"
```

- 不写 `--agent` 就用当前默认任务大脑。
- 不写 `--cwd` 就用默认工作区。
- 任务和聊天大脑是两个独立进程，互不打断。

微信里：

```text
任务：把 docs 里的接入方案整理成一页说明
任务 codex：跑一遍测试并总结失败项
```

## 看状态

```bash
wemind task-list
wemind task-status
wemind task-status 2
```

微信里：

```text
任务列表
/tasks
```

每条任务会显示编号、状态、最近输出、Agent、轮次、时长。

## 回复任务

任务在等你决策时，会通过微信推一条消息。回复时带编号：

```bash
wemind task-reply 2 "选方案 B，继续"
```

微信里：

```text
#2 选方案 B，继续
/reply 2 选方案 B，继续
```

不带 `#编号` 的消息默认走聊天大脑，不会进任务。想先指定收件人，可以发：

```text
发给任务 2
#2
```

之后的文字和附件会交给任务 2；发 `好了` / `就这样` 提交，或等 3 分钟自动提交。

## 结束

```bash
wemind task-stop 2
wemind task-stop all
```

微信里：

```text
结束任务 2
结束全部任务
```

- 任务在“等你回复”时结束：进程留着复用，不浪费一次冷启动。
- 任务在“正在跑”时结束：ACP 回合没法优雅取消，只能力杀。
- 多条任务并存时，结束单条必须带编号，避免误杀。

## 进程池与重启

- 默认最多 3 个 worker，空闲超过 5 分钟回收。
- 每条任务一条 ACP 连接；可以同时让不同 Agent 跑不同任务。
- daemon 重启后，未完成任务会标成「待继续」，**不会自动重新跑**。你回「继续」或执行 `wemind task-resume-all` 才续跑。
- 聊天记录本身就是归档，WeMind 不做任务历史归档。

## 附件

给任务发图片/文件/视频时，先设收件人，再发附件，最后用一句话提交：

```text
发给任务 2
[图片]
[文件]
按这个改，改完告诉我
```

附件会先暂存，等队列安静约 700ms 再一起提交。没有收件人时，带附件的消息会进聊天大脑，不会进任务。

## 什么时候用任务，不用聊天

| 场景 | 用哪个 |
| --- | --- |
| 问一句、改一句、马上要答案 | 聊天大脑 |
| 跑测试、读整个仓库、批量改文件 | 远程任务 |
| 需要你中途选方案 | 远程任务（它会推微信） |
| 多个互不依赖的活 | 多个任务，不同 Agent |
