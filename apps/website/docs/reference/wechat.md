# 微信指令

这些消息由 daemon 拦截，不会进 Agent。中文和斜杠两种写法都认；`/ai` 是统一前缀。

## 大脑与 Agent

| 你发 | 作用 | 范围 |
| --- | --- | --- |
| `切换大脑 [名]` · `/ai brain [名]` · `/brain [名]` | 换对话大脑，不重启、不打断在途回合 | 整个账号，仅登录者 |
| `切换任务大脑 [名]` · `/ai task [名]` · `/worker [名]` | 设默认任务大脑，只在本次运行内生效 | 整个账号，仅登录者 |
| `AI` / `AI 列表` · `/ai` | 列可选 Agent、当前对话/任务大脑 | 整个账号，仅登录者 |
| `交接` · `/handoff` | 生成交接摘要，换大脑后第一条消息自动带上 | 整个账号，仅登录者 |

> 前四条是 owner-only：非登录者发会被拦下，不会转发给 Agent。

## 会话

| 你发 | 作用 |
| --- | --- |
| `新会话 [名字]` · `/new` | 清当前会话并新建 |
| `会话列表 [页]` · `/sessions` | 看序号、名字/摘要、时间、轮次、`←当前` |
| `恢复会话 <序号\|名字\|id前缀>` · `/resume` | 严格恢复；接不上就报错 |
| `重命名会话 <序号\|名字> <新名字>` · `/rename` | 改名 |
| `删除会话 <序号>` · `/delete` | 从列表删除；当前会话会清指针 |

## 任务

| 你发 | 作用 |
| --- | --- |
| `任务 [<agent 名>：]正文` · `/task` | 派发新任务 |
| `#<编号> 正文` · `/reply <编号> 正文` | 回复指定任务 |
| `任务列表` · `/tasks` | 一条任务一行 |
| `结束任务 [编号]` / `结束全部任务` · `/stop` | 结束任务 |
| `全部继续` · `task-resume-all` | 重启后继续所有「待继续」任务 |

## 收件人

| 你发 | 作用 |
| --- | --- |
| `#<编号>` / `发给任务 <编号>` | 把后续文字/附件交给这个任务 |
| `好了` / `就这样` | 提交暂存附件并让任务继续 |

## 工作区与配置

| 你发 | 作用 |
| --- | --- |
| `工作区` · `/workspace` | 看当前工作区 |
| `设置工作区 <路径>` | 设置默认工作区 |
| `重置工作区` | 恢复默认 |
| `微信配置` | 看微信独享配置 |
| `允许敏感文件 [分钟]` | 临时放行敏感文件，默认 2 分钟，最长 30 分钟 |
| `加载 MCP <名>` / `卸载 MCP <名>` | managed 模式下加载/卸载 MCP |
| `帮助` · `/help` | 按角色列出可用指令 |

## 会话与任务的归属

- 会话和任务按**登录者**隔离；每个账号有自己的 daemon、bot 和登录者。
- 账号之间没有“主号”，谁也管不了谁。
- 切换大脑只影响当前账号；任务大脑只在本次运行内生效。

## 没反应怎么办

1. 确认 daemon 在跑：`wemind list`。
2. 看日志：`wemind log --errors`。
3. 确认没有同时开 MCP 形态：同一个 bot token 只能一个程序收消息。
4. 确认你是登录者；owner-only 指令对其他人不生效。
