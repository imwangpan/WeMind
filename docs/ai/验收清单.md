| ----------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 纯逻辑                        | `npm run typecheck` + `npm test`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| agent 配置/沙箱               | `wemind brain` + `wemind brain check` + 单测                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| **Cline**                     | `npm i -g cline`；`wemind brain set cline` 后 `wemind brain check`（OAuth 登录直接过；自定义 provider 由 `credentialEnv` 自动复用 `providers.json` 的 key，显式 env 优先）；`加载 <mcp>` 后看沙箱 `cline/mcp.json`；杀 daemon 再起，追问上下文仍在（`session/load`）                                                                                                                                                                                                                                                                                                           |
| **Gemini 接入**               | 终端 `gemini --version`（0.66+）并完成认证（`~/.gemini/settings.json` 的 `security.auth.selectedType` + `~/.gemini/.env` 的 key/base URL）；`wemind brain set gemini` 后 `wemind brain check`；`ACP_TEST_TOOL=1` 跑探针（yolo 下 0 权限请求）；沙箱看 `brain-home/.gemini/settings.json`（有 model/security、无真实 MCP、`general.enableAutoUpdate=false`）与凭据文件（`.env`；Google 登录另看 `oauth_creds.json` / `google_accounts.json`）；杀 daemon 再起，追问上下文仍在且**答复里没有旧历史回放**（`replayOnLoad`）；`加载 <MCP>` 后下条消息能调到该工具、`wechat` 仍被拒 |
| **模型跟随日常 agent**（DSH） | 真实 `~/.dsh/profiles/acp/cordis.patch.yml` 里有 `- id: acp`（`wemind brain` 会给可粘贴的片段）；沙箱那份与真实**逐字节一致**（WeMind 不追加）；`wemind brain`「生效」`model=` = 该文件里的值（优先 `- id: acp`，否则 `agent-default-model`）；`- id: acp` 的 model 已不在 provider 目录时 `wemind brain` 给出 `no configured model` 的替换提示（**不自动改文件**）；桌面端改模型 → 重启 daemon 或 `wemind brain switch deepseek` 后跟着变（改过 `brain.json` 的显式 `model` 则不跟随）                                                                                        |
| **DSH 会话隔离**              | 先让别的 agent（如 pi）在 `brain-home/` 写过 `sessions/`，再 `wemind brain check` / 微信单轮：DSH 能正常起会话（不报 `unsupported flat-file layout`）；`<账号目录>/agent-sessions/deepseek/session-root-brain.patch.yml` 与 `.../brain/` 已生成，`worker` 角色各一份；重启 daemon 追问上下文仍在（`resume`）；用户 `--args` 自带 `--patch` 时不再追加                                                                                                                                                                                                                          |
| **kiro v3**                   | 真实 `~/.kiro/settings/cli.json` 设 `"acp.agentEngine": "v3"`（或 `wemind brain set kiro --args "acp --agent-engine v3"`）；`wemind brain` 显示 `args=[acp --agent-engine v3]`（v2 的 `--trust-all-tools` 已被剔除）；`wemind brain check` 握手通过；沙箱 `brain-home/settings/permissions.yaml` 是 allow-all 规则（真实设置已有则原样保留）；微信一轮 + 让大脑写文件不被权限拦                                                                                                                                                                                                |
| ACP 协议                      | 冒烟：`initialize → session/new → prompt → update`；重建后 `load/resume`；无未应答反向请求                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| 消息/回复                     | 真机微信一条消息 → `daemon.log` 出现 `prompt ok` → 收到回复                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| MCP                           | `加载 <名>` → 下条消息生效；`wechat` 仍被禁止                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| worker                        | 派发任务 → 中断 → 回「继续」→ 能续上                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| **热切换大脑**                | 真机 kiro↔opencode；启动新大脑期间发消息**只 spawn 一次**（看 log）；未知/不可用的 agent 被拒；故意坏 bin → 回滚 + 旧大脑继续答 + `brain.json` 未变                                                                                                                                                                                                                                                                                                                                                                                                                            |
| **多任务并行 / 寻址**         | `任务 kiro：…` + `任务 opencode：…` 同时跑且都出结果；第三条超上限被拒；结束「等你回复」的任务后进程留着复用、空闲 5 分钟后消失（`wemind list`/进程管理器验；结束「正在跑」的那条只能力杀）；`wemind stop` 一次杀光所有 worker；**任务出结果后发无编号普通消息 → 走大脑**，发 `#n 正文` 才进任务（推送末尾有这行提示）                                                                                                                                                                                                                                                         |
| **任务中断续跑**              | 跑到一半 `taskkill` daemon → 重启后 `任务列表` 显示「已中断」→ 回「继续」上下文确实接上；agent 不支持恢复时给诚实文案且编号连续                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| **provider 报错转「已中断」** | 派一条注定失败的任务（如 DSH 余额不足）→ 推送说「中断了（额度/余额不足）」且 `任务列表` 显示「已中断」→ 之后发一条**无编号**的普通消息要**走大脑**（不能白喂给那条任务）→ **账号修好后**回 `#n 继续` 能续跑（没修好时续跑只是又失败一轮、退回「已中断」，这是预期）                                                                                                                                                                                                                                                                                                            |
| **pi 接入**                   | `npm i -g @earendil-works/pi-coding-agent` + 终端 `pi` 登录 + `npm i -g pi-acp`；`wemind brain set pi` → `wemind brain`（bin=`pi-acp(.cmd)`、args=[]、MCP=`mcp.json`）→ `wemind brain check`；`ACP_TEST_TOOL=1` 跑探针；真机微信一轮 + 杀 daemon 后 `session/load` 追问上下文仍在 + `加载 <MCP>` 后 `pi mcp list` 能看到 server 且下条消息生效、`wechat` 仍被拒                                                                                                                                                                                                                |
| **Claude Code 接入**          | `npm i -g @agentclientprotocol/claude-agent-acp`；`wemind brain set claude-code --restart` → `wemind brain`（bin=`claude-agent-acp(.cmd)`、args=[]、`session_mode=bypassPermissions`）→ `wemind brain check`（结论带 `mode=bypassPermissions`）；真机微信一轮消息 + 杀 daemon 后追问上下文仍在（`session/load`）+ `加载 <MCP>` 生效且 `wechat` 仍被拒                                                                                                                                                                                                                          |
| **重启后补发**                | 重启 daemon → **不在微信发消息**、本地派一条任务 → 日志见「`send -2（旧 token）→ 挂起`」→ 微信发任意一条消息 → 日志「`新 token 已到 → 补发挂起消息 N 条`」且结果真的收到（旧 token 的 `-2` 不再静默丢）                                                                                                                                                                                                                                                                                                                                                                        |
| **会话四件套**                | 会话 A 塞暗号 → 新会话 → 列表 → 恢复 → 暗号回来；恢复不存在的 id → 失败且当前会话不变；删当前会话后下条消息开新的；会话与任务只见登录者自己的                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| **交接**                      | 交接 → 切脑 → 问只靠旧上下文能答的问题 → 文件已消费、第二条不重复带上                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| **CLI 热切换 / 控制桥**       | daemon 在跑时 `wemind brain switch` 免重启生效；daemon 停时 `session list` 仍可用；`session rename` 后微信 `会话列表` 可见；旧版 daemon → 「必须由 daemon 执行」的命令发前拒绝，文件类命令照常（`session list` 附一行说明）                                                                                                                                                                                                                                                                                                                                                    |

日志前缀：`[wemind/wechat-daemon]`、`.../acp`、`.../worker`、`.../task`、`.../watchdog`、`.../wrapper`。
