# WeMind 全局审查清单（2026-11-02）

> 范围：代码健壮性、设计合理性、测试覆盖、代码与文档一致性、文档用语、多账号隔离。
> 基线：`main` @ `ac698f0`；`NODE_OPTIONS='' npm test` → 49 个文件、530 通过、2 跳过。
> 用法：按 P1 → P2 → P3 修复；每批只改一个主题，代码 + 测试 + 文档同批提交。修复后把 `[ ]` 改成 `[x]`。

## 0. 结论摘要

- 单账号主链路（登录 → 长轮询 → 回合 → 回复 → 任务/会话/切脑）整体可用，已有较多真机验证。
- 最需要先处理的是**失败路径的静默数据损坏**：持久化读失败当空表、最终答复被额度挤掉、会话恢复被模型设置失败拖成新建。
- **多账号不是「多发送者」问题**：一个微信账号只有登录者一个发送者；多账号是**多个 daemon、各自数据目录**。真正的共享面是 `accounts.json`、`.staging/`、PowerShell 脚本根目录，以及少数 agent 仍读写真实 home 的配置。
- 文档总体质量高，但「可照抄性」有缺口：自启示例、环境变量表、接入状态表、少量重复词。
