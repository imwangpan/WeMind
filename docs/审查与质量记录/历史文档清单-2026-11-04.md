## 需要注意

- `CHANGELOG.md` 移出仓库根后，**没有任何自动化依赖受影响**：本项目的 npm 包从 `packages/*/` 子目录打包（实测 `npm pack --dry-run` 的 Tarball Contents 只有 LICENSE / README.md / dist / package.json，不含 CHANGELOG.md），`.github/workflows/` 与 `scripts/` 也从不读取它，GitHub 不把它当特殊文件解析（自动渲染的只有 README.md）。实际影响仅为根目录路径约定与外部旧 `blob/main/CHANGELOG.md` 链接；若日后要恢复该约定，移回根目录并同步引用即可。
