# WeMind 新手教程：从零搭起你的微信 AI

> 面向第一次接触 WeMind 的人。只要你**会装软件、能照着复制命令**，就能跟着走完。
> 看不懂的名词可以直接略过，照着做即可。

---

## 0. 这能帮你做什么

WeMind 让 AI 通过**你的个人微信**收发消息。有两种用法，按需求二选一（也可都用）：

- **路线一 · 当工具用**：在你已经在用的 AI 客户端（Claude Desktop、Cursor、OpenCode 等）里，加一个「收发微信」的能力。你在客户端里让 AI 看微信、回微信。
- **路线二 · 当助手用**：跑一个**常驻服务**，AI 自动 24 小时收你微信、自动回复，还能把耗时任务交给它远程遥控。这才是 _Your AI mind, reachable on WeChat_ 的完整体验。

| | 路线一 · MCP 接入 | 路线二 · wemind 助手 |
| --- | --- | --- |
| 适合 | 已经在用某个 AI 客户端 | 想要独立的微信 AI 助手 |
| AI 大脑从哪来 | 你的客户端自带 | wemind 自带（默认 kiro-cli） |
| 在线时间 | 开着客户端时 | 24/7 常驻（开机自启） |
| 难度 | ★ 容易 | ★★ 中等 |

## 1. 开始前的准备

### 1.1 一个微信（无需任何申请）

WeMind 走腾讯官方的「微信 ClawBot」通道。**你不需要申请什么资格、白名单**——稍后登录时 WeMind 会生成一个二维码（和链接），你用微信扫一下就自动接入了。准备一个能扫码的微信即可。

> 限制先说清楚：①bot **不能主动发起对话**，只能在你（或别人）先发消息后回复；②这是腾讯新功能，官方可能随时调整，别用于关键业务。

### 1.2 Node.js 20+

WeMind 用 Node.js 运行。

1. 打开 <https://nodejs.org>，下载 **LTS** 版本，一路「下一步」装完。
2. 打开终端（Windows 用 PowerShell，Mac/Linux 用 Terminal），输入：
   ```bash
   node -v
   ```
   看到 `v20.x` 或更高就对了。

### 1.3 （只有路线二需要）一个 AI 大脑

路线二的「自动回复」需要一个 AI agent 当大脑。WeMind **实测跑通的是 [kiro-cli](https://kiro.dev)**（默认大脑）。装好后确认终端能运行：

```bash
kiro-cli --version
```

> 也支持任何兼容 **ACP** 协议的 agent（gemini、opencode 等），换大脑见「进阶」。路线一不需要这步——AI 由你的客户端提供。

## 路线一：在 AI 客户端里收发微信（MCP）

### 第 1 步：把 WeMind 加进你的客户端

WeMind 的 MCP 包叫 `@wemind/wechat-mcp`。

**▶ 方式 A（发布之后，推荐）**——直接用 `npx`，无需安装：

Claude Desktop（`claude_desktop_config.json`）/ Cursor：
```json
{
  "mcpServers": {
    "wechat": { "command": "npx", "args": ["-y", "@wemind/wechat-mcp"] }
  }
}
```

OpenCode（`opencode.json`）：
```json
{
  "mcp": {
    "wechat": { "type": "local", "command": ["npx", "-y", "@wemind/wechat-mcp"], "enabled": true }
  }
}
```

> **不知道配置文件在哪 / 不想手动改？** 直接对你的 AI 说：
> 「帮我把一个叫 wechat 的 MCP 服务加到配置里，启动命令是 `npx -y @wemind/wechat-mcp`」——现在的 AI 客户端基本都能自己改好。

**▶ 方式 B（当前还没发布到 npm 时）**——先用源码构建，再用绝对路径指向产物：
```bash
git clone https://github.com/imwangpan/WeMind.git
cd WeMind
npm install
npm run build
```
然后配置里把 `command`/`args` 换成：
```json
{ "command": "node", "args": ["/你的绝对路径/WeMind/packages/wechat-mcp/dist/index.js"] }
```

### 第 2 步：扫码登录

重启你的 AI 客户端，对它说：**「登录微信」**。它会调 `login_qrcode` 生成二维码——终端文本码、PNG 图片、链接三种任选其一，用手机微信扫。

> 扫码后页面一直转圈？**切到手机流量（关掉 WiFi）**再扫，多数情况能解决。

扫完再让 AI「检查登录状态」，显示已确认即成功。

### 第 3 步：开始收发

对 AI 说「看看有没有新的微信消息」，它就会：收消息 → 显示「正在输入…」→ 回复。之后你就能让它替你看微信、回微信了。

### 能用的工具一览

| 工具 | 作用 |
| --- | --- |
| `login_qrcode` | 生成登录二维码 |
| `check_qrcode_status` | 检查是否扫码确认 |
| `logout` | 退出登录 |
| `get_messages` | 收新消息（可阻塞等待） |
| `send_text_message` | 发文本 |
| `send_typing` | 显示 / 取消「正在输入」 |

## 路线二：常驻的微信 AI 助手（wemind）

### 第 1 步：安装 wemind

**▶ 发布之后（推荐）**：
```bash
npm i -g wemind
```
装完终端就有了 `wemind` 命令。

**▶ 当前还没发布时**：从源码构建后直接用 `node` 跑产物：
```bash
git clone https://github.com/imwangpan/WeMind.git
cd WeMind
npm install
npm run build
```
之后凡是教程里写 `wemind xxx` 的地方，都替换成：
```bash
node packages/wechat-daemon/dist/cli.js xxx
```
（例如 `wemind login` → `node packages/wechat-daemon/dist/cli.js login`）

### 第 2 步：登录

```bash
wemind login --label 我的号 --start
```

- 它会自动弹出二维码（终端里显示 + 自动打开 PNG 图片），用微信扫码确认。
- `--label 我的号` 给这个账号起个好记的别名。
- `--start` 表示登录后顺便启动常驻。

### 第 3 步：让它常驻（崩溃自愈 + 开机自启）

`wemind start` 默认用**自带看门狗**（零依赖：崩溃自动重拉 + 脱离终端）：

```bash
wemind start 我的号
```

这一条就让它在后台保活了（崩了会自动重启）。剩下的是**开机自启**——让你重启电脑后它也自动起来，按你的系统选一种：

**Windows**：`Win+R` 输入 `shell:startup` 打开启动文件夹，放一个 `.bat`：
```bat
@echo off
wemind start 我的号
```
或用「任务计划程序」建一个「登录时触发」、执行 `wemind start 我的号` 的任务。

**Linux**（systemd user service）：建 `~/.config/systemd/user/wemind.service`：
```ini
[Unit]
Description=WeMind
[Service]
ExecStart=wemind start 我的号
Restart=always
[Install]
WantedBy=default.target
```
再执行 `systemctl --user enable --now wemind`，并 `loginctl enable-linger $USER`（注销/关机后仍保活）。

**macOS**（launchd）：在 `~/Library/LaunchAgents/` 放一个 plist，`ProgramArguments` 设为 `wemind start 我的号`、`RunAtLoad` 设为 true，再 `launchctl load` 它。

> **想用 pm2 管也行**（崩溃重拉 + 自启更省心，代价是多装一个 pm2）：`npm i -g pm2`，然后 `wemind start 我的号 --runner pm2` + `pm2 save` + `pm2 startup`（Windows 下 `pm2 startup` 较弱，用计划任务跑 `pm2 resurrect`）。

### 第 4 步：验证它活了

用**另一个**微信给你登录的这个号发一条消息，看它是否自动回复。或者查看运行状态：

```bash
wemind list
```
能看到账号、别名、`运行中(pid …)` 即正常。

### 日常怎么用

直接用微信跟它聊就行。几个常用「口令」（在微信里发给 bot）：

| 你发的消息 | 效果 |
| --- | --- |
| 任意普通消息 | 正常对话 |
| `新会话` / `重置` | 清空上下文、开新对话 |
| `列出 MCP` | 看可加载的工具集 |
| `加载 <名字>` | 临时给大脑加一个 MCP 工具 |
| `任务：<描述>` | 派一个远程任务（见下） |

- **发图片**：让它发图时，它会在回复里给出图片链接，wemind 自动下载并作为图片发给你。
- **模型**：它会继承你本机 kiro 的模型设置（在 kiro 里配的是哪个模型，微信大脑就用哪个）。

### 远程任务（进阶玩法）

把耗时任务交给它，你离开电脑也能用微信遥控：

- 在微信发 `任务：把这个项目的测试补全`，它开始干；需要你拍板（如「选哪个方案」）时会推到微信，你回一句它就继续。
- 也能在**电脑终端**直接派，还能指定工作目录：
  ```bash
  wemind task "把这个项目的测试补全" --cwd /path/to/项目
  wemind task-status    # 看进度
  wemind task-reply 继续 # 回复 / 让它续跑
  wemind task-stop      # 结束
  ```

### 多账号

`wemind login` 多跑几次就能登录多个微信号，各自独立、互不干扰：

```bash
wemind login --label 工作号 --start
wemind login --label 私人号 --start
wemind list           # 查看所有账号
wemind stop 工作号     # 停某个
```

## 常见问题（FAQ）

- **扫码后页面一直加载** → 切到手机流量（关 WiFi）再扫。
- **登录后大脑不回复**（路线二）→ 确认 `kiro-cli` 能在终端跑；确认它配了可用的模型；看日志 `~/.wemind/<账号>/daemon.log`。
- **`wemind` 命令找不到**（路线二、发布前）→ 你还没发布安装，用 `node packages/wechat-daemon/dist/cli.js …` 代替。
- **Windows 开机自启没生效** → `pm2 startup` 在 Windows 不原生支持，用任务计划程序跑 `pm2 resurrect`。
- **会话过期 / 一段时间收不到** → iLink 会话超时（约 1 小时冷却），重新发条消息即可恢复。
- **隔一会儿就不回了** → 一轮里 bot 连续发太多条会被限流，回复「继续」即可恢复（长任务常见）。

## 安全须知（务必读）

- **路线二的大脑用 `--trust-all-tools`**：意味着**任何能给这个 bot 发消息的人，都能让 AI 在你电脑上执行任意操作（含运行命令、读写文件）**。唯一的安全闸是**发件人授权**——只有授权用户的消息才会被处理，**扫码登录你自己会被自动授权**，请**不要关掉这道闸**。需要给别人开权限用 `wemind allow <账号> <对方 userId>`。
- **凭证存储**：登录凭证存在 `~/.wemind/<账号>/account.json`。**Windows 上是明文**，请用文件夹权限或磁盘加密保护。
- **隐私**：消息会经过腾讯 iLink 通道和你本地的 AI 流转，涉及对话内容外发，请自行评估再用。

## 卸载 / 重置

- **停止常驻**：`wemind stop <账号>`（pm2 方式再 `pm2 delete wemind-<key>`）。
- **退出登录**：`wemind logout <账号>`（停服务 + 下线 + 清凭证，保留目录可重登）。
- **彻底删除某账号**：`wemind delete <账号>`（连目录一起删）。
- **重置对话记忆**：删 `~/.wemind/<账号>/brain-sessions.json` 与 `brain-home/sessions/`。
