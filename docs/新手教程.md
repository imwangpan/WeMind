# WeMind 新手教程：从零搭起你的微信 AI

> 面向第一次接触 WeMind 的人。只要你**会装软件、能照着复制命令**，就能跟着走完。
> 看不懂的名词可以直接略过，照着做即可。
>
> **适用版本**：WeMind 1.2.0 ｜ **最后核对**：2026-10-30（两个包均已发布到 npm：`@wemind/cli`、`@wemind/wechat-mcp`）

---

## 0. 这能帮你做什么

WeMind 让 AI 通过**你的个人微信**收发消息。有两种用法，按需求二选一（也可都用）：

- **路线一 · 当工具用**：在你已经在用的 AI 客户端（Claude Desktop、Cursor、OpenCode 等）里，加一个「收发微信」的能力。你在客户端里让 AI 看微信、回微信。
- **路线二 · 当助手用**：跑一个**常驻服务**，AI 自动 24 小时收你微信、自动回复，还能把耗时任务交给它远程遥控。这才是 _Your AI mind, reachable on WeChat_ 的完整体验。

| | 路线一 · MCP 接入 | 路线二 · wemind 助手 |
| --- | --- | --- |
| 适合 | 已经在用某个 AI 客户端 | 想要独立的微信 AI 助手 |
| AI 大脑从哪来 | 你的客户端自带 | wemind 自带（ACP agent，默认自动探测已安装者） |
| 在线时间 | 开着客户端时 | 24/7 常驻（开机自启） |
| 难度 | ★ 容易 | ★★ 中等 |

## 1. 开始前的准备

### 1.1 一个微信（无需任何申请）

WeMind 走腾讯官方的「微信 ClawBot」通道。**你不需要申请什么资格、白名单**——稍后登录时 WeMind 会生成一个二维码（和链接），你用微信扫一下就自动接入了。准备一个能扫码的微信即可。

> 限制先说清楚：①bot **不能主动发起对话**，只能是**你先发消息**、它再回复（微信平台只把发给它的消息发送给登录者本人，也就是你）；②这是腾讯新功能，官方可能随时调整，别用于关键业务。

### 1.2 Node.js 20+

WeMind 用 Node.js 运行。

1. 打开 <https://nodejs.org>，下载 **LTS** 版本，一路「下一步」装完。
2. 打开终端（Windows 用 PowerShell，Mac/Linux 用 Terminal），输入：
   ```bash
   node -v
   ```
   看到 `v20.x` 或更高就对了。

### 1.3 （只有路线二需要）一个 AI 大脑

路线二的「自动回复」需要一个 AI agent 当大脑。WeMind **已实测 [kiro-cli](https://kiro.dev)、[OpenCode](https://opencode.ai)、官方 DSH（DeepSeek）、Qoder CLI 与 [Cline](https://cline.bot)，以及 Claude Code（经 ACP 适配器，探针级实测）**；未配置时默认 `auto`（按 kiro → opencode → gemini → deepseek → qoder → cline 探测已安装者）。装好后确认终端能运行：

```bash
kiro-cli --version
# 或 opencode --version
# 或 qodercli --version
# 或 cline --version
```

> Qoder 需先 `qoder login`；WeMind 会自动同步登录态到大脑沙箱（详见 [接入-Qoder.md](接入-Qoder.md)）。Cline 用 `npm i -g cline` 安装（`cline auth` 登录）；**自定义/API-key provider 不用手动配 key**——WeMind 会从 `providers.json` 自动读取 `lastUsedProvider` + `apiKey` 并转成 Cline ACP 需要的环境变量（详见 [接入-Cline.md](接入-Cline.md)）。Claude Code 要先全局安装适配器 `npm i -g @agentclientprotocol/claude-agent-acp`（Node ≥22）并完成 `claude` 登录，再 `wemind brain set claude-code`（详见 [接入-ClaudeCode.md](接入-ClaudeCode.md)）。也支持其它能说 **ACP** 的 agent（gemini 等），换大脑见「进阶」。路线一不需要这步——AI 由你的客户端提供。

## 路线一：在 AI 客户端里收发微信（MCP）

### 第 1 步：把 WeMind 加进你的客户端

WeMind 的 MCP 包叫 `@wemind/wechat-mcp`。

**▶ 方式 A（推荐）**——该子包已发布到 npm，直接用 `npx`，无需安装：

Claude Desktop（`claude_desktop_config.json`）/ Cursor：
```json
{
  "mcpServers": {
    "wechat": { "command": "npx", "args": ["-y", "@wemind/wechat-mcp"] }
  }
}
```

OpenCode（`opencode.json`，V2：server 定义在 `mcp.servers` 下）：
```json
{
  "mcp": {
    "servers": {
      "wechat": { "type": "local", "command": ["npx", "-y", "@wemind/wechat-mcp"] }
    }
  }
}
```

> **不知道配置文件在哪 / 不想手动改？** 直接对你的 AI 说：
> 「帮我把一个叫 wechat 的 MCP 服务加到配置里，启动命令是 `npx -y @wemind/wechat-mcp`」——现在的 AI 客户端基本都能自己改好。

**▶ 方式 B（本地开发 / 离线）**——先用源码构建，再用绝对路径指向产物：
```bash
git clone https://github.com/imwangpan/WeMind.git
cd WeMind
npm install
npm run build
```
然后配置里把 `command`/`args` 换成：
```json
{ "command": "node", "args": ["/你的绝对路径/WeMind/packages/wechat-mcp/dist/index.js"] }
```

### 第 2 步：扫码登录

重启你的 AI 客户端，对它说：**「登录微信」**。它会调 `login_qrcode` 生成二维码——终端文本码、PNG 图片、链接三种任选其一，用手机微信扫。

> 扫码后页面一直转圈？**切到手机流量（关掉 WiFi）**再扫，多数情况能解决。

扫完再让 AI「检查登录状态」，显示已确认即成功。

### 第 3 步：开始收发

对 AI 说「看看有没有新的微信消息」，它就会：收消息 → 显示「正在输入…」→ 回复。之后你就能让它替你看微信、回微信了。

### 能用的工具一览

| 工具 | 作用 |
| --- | --- |
| `login_qrcode` | 生成登录二维码 |
| `check_qrcode_status` | 检查是否扫码确认 |
| `logout` | 退出登录 |
| `get_messages` | 收新消息（可阻塞等待） |
| `send_text_message` | 发文本 |
| `send_typing` | 显示 / 取消「正在输入」 |

## 路线二：常驻的微信 AI 助手（wemind）

### 第 1 步：安装 wemind

**▶ 已发布到 npm（推荐）**：
```bash
npm i -g @wemind/cli      # 包名是 @wemind/cli，装完命令仍是 wemind
```
装完终端就有了 `wemind` 命令，可以先验证一下：
```bash
wemind version            # → wemind 1.2.0 (@wemind/cli, node …, win32-x64)   # 版本以实际安装为准
```
临时用、不安装的话写全包名：`npx -y @wemind/cli version`（注意 `npx wemind` 不行，因为包名与命令名不同）。

**▶ 想改代码 / 从源码跑**：clone 后构建，再用 `node` 跑产物：
```bash
git clone https://github.com/imwangpan/WeMind.git
cd WeMind
npm install
npm run build
```
之后凡是教程里写 `wemind xxx` 的地方，都替换成：
```bash
node packages/wechat-daemon/dist/cli.js xxx
```
（例如 `wemind login` → `node packages/wechat-daemon/dist/cli.js login`）

> 💡 **要先装一个「大脑」**：`wemind` 自己不产生智能，它把消息交给一个实现 **ACP** 协议的 agent CLI。常见的有 `kiro-cli`、`opencode`、`qodercli`、`cline`、桌面端 `dsh`。不配置时它会按 `kiro → opencode → gemini → deepseek → qoder → cline` 自动探测；装好后用 `wemind brain check` 验证能否握手成功。
>
> 想给大脑的启动命令**加参数**（例如只对这一个账号加某个开关）：用 `wemind brain set <agent 名> --extra-args "--某个开关"`——它追加在预设参数之后，不会弄丢 `acp` 这类 ACP 模式参数；`--args "…"` 是整段替换，慎用。**内置预设已各自默认免审批**（见文末「安全须知」），通常不需要再补免确认开关。

### 第 2 步：登录

```bash
wemind login --label 我的号 --start
```

- 它会自动弹出二维码（终端里显示 + 自动打开 PNG 图片），用微信扫码确认。
- `--label 我的号` 给这个账号起个好记的别名。
- `--start` 表示登录后顺便启动常驻。

### 第 3 步：让它常驻（崩溃自愈 + 开机自启）

`wemind start` 默认用**自带后台守护进程**（零依赖：崩溃自动重拉 + 脱离终端）：

```bash
wemind start 我的号
```

这一条就让它在后台保活了（崩了会自动重启）。剩下的是**开机自启**——让你重启电脑后它也自动起来，按你的系统选一种：

**Windows**：`Win+R` 输入 `shell:startup` 打开启动文件夹，放一个 `.bat`：
```bat
@echo off
wemind start 我的号
```
或用「任务计划程序」建一个「登录时触发」、执行 `wemind start 我的号` 的任务。

**Linux**（systemd user service）：建 `~/.config/systemd/user/wemind.service`：
```ini
[Unit]
Description=WeMind
[Service]
ExecStart=wemind start 我的号
Restart=always
[Install]
WantedBy=default.target
```
再执行 `systemctl --user enable --now wemind`，并 `loginctl enable-linger $USER`（注销/关机后仍保活）。

**macOS**（launchd）：在 `~/Library/LaunchAgents/` 放一个 plist，`ProgramArguments` 设为 `wemind start 我的号`、`RunAtLoad` 设为 true，再 `launchctl load` 它。

> **想用 pm2 管也行**（崩溃重拉 + 自启更省心，代价是多装一个 pm2）：`npm i -g pm2`，然后 `wemind start 我的号 --runner pm2` + `pm2 save` + `pm2 startup`（Windows 下 `pm2 startup` 较弱，用计划任务跑 `pm2 resurrect`）。`wemind` 会把 app 声明写进账号目录的 `pm2.app.json`，崩溃 5 秒重拉、大脑配置错误（退出码 78）不再重启——和自带后台守护进程一样。

### 第 4 步：验证它活了

用**你自己的微信**给这个 bot 发一条消息（如「你好」），看它是否自动回复。**别的微信号发不进来**——微信平台只允许登录者本人给这个 bot 发消息。没回复时看 `~/.wemind/<账号>/daemon.log` 有没有 `recv msg`（有 = 消息到了 daemon）。也可以查看运行状态：

```bash
wemind list
```
能看到账号、别名、`运行中(pid …)` 即正常。

### 日常怎么用

直接用微信跟它聊就行。几个常用「口令」（在微信里发给 bot）：

| 你发的消息 | 效果 |
| --- | --- |
| 任意普通消息 | 正常对话 |
| `新会话 [名字]` / `重置` | 开一条全新对话（可以起个名字，以后好认） |
| `会话列表` / `恢复会话 <序号或名字>` | 翻看 / 切回以前的对话 |
| `重命名会话 <序号> <名字>` / `删除会话 <序号>` | 给会话起名（方便以后认出来）/ 从列表里删掉 |
| `切换大脑 [名字]` | 换一个 AI 大脑（当场生效，不用重启） |
| `列出 MCP` | 看可加载的工具集 |
| `加载 <名字>` | 临时给大脑加一个 MCP 工具 |
| `任务：<描述>` | 派一个远程任务（见下） |
| `任务列表` / `结束任务` | 看任务 / 结束任务 |
| `交接` | 让它写一份对话摘要，换大脑后新的那个自动接手 |
| `帮助` | 列出全部可用指令 |

- **发图片**：让它发图时，它会在回复里给出图片链接，wemind 自动下载并作为图片发给你。
- **模型**：它会继承你本机 kiro 的模型设置（在 kiro 里配的是哪个模型，微信大脑就用哪个）。
- **换大脑不用重启**：它会先把正在说的那条话说完，再试着把新大脑拉起来——**成功了才记住**；要是新大脑起不来，它会自动退回原来那个并告诉你一声（「已退回原来那个 X」），你什么都不用做。
- **前四个口令是「账号级」的**（在代码里只有登录者能发；何况微信平台本来就只有你能给这个 bot 发消息）：`AI` / `切换大脑` / `切换任务大脑` / `交接`——它们影响整个账号的大脑。**会话管理（新会话 / 会话列表 / 恢复会话 / 重命名 / 删除）和任务指令（派发、`#n` 回话、任务列表、结束任务）是「登录者自己的」**：永远只属于你一个人。
- **换大脑只影响你登录的这个微信号**：多个微信号各跑各的 daemon，换一个的大脑不会影响其它账号。差别与限制见 README 的[多账号管理](../README.md#多账号管理)。
- **也能用斜杠写法**：这些口令大多有等价写法（`/new`、`/sessions`、`/brain`、`/tasks`…）；大脑相关的统一用 `/ai` 前缀——`/ai` 看当前与可选、`/ai brain` 换对话大脑、`/ai task` 换任务大脑。记不住就发 `帮助`。

### 远程任务（进阶玩法）

把耗时任务交给它，你离开电脑也能用微信遥控（**可以同时开好几条**）：

- 在微信发 `任务：把这个项目的测试补全`，它开始干；需要你拍板（如「选哪个方案」）时会推到微信，你回一句它就继续。
- **想用别的大脑干这条活**：`任务 kiro：整理本周周报`——冒号前写一个已装好的大脑名字（kiro / opencode / qoder…），这条任务就交给它，而且**总是新开一条**任务。`任务 明天：去买菜` 这种冒号前不是大脑名的，不当成指定 agent——整串（连「明天：」一起）仍是正文，照旧派给任务侧；想只跟大脑说话用「问大脑 …」。
- **想换默认用哪个大脑跑任务**：微信发 `切换任务大脑 <名字>`（不带名字只回「当前默认任务大脑：X」；看可选 agent 用 `AI` / `/ai`）；它只管「不指定大脑的任务」，**重启后回到配置里的默认值**。终端里对应 `wemind brain switch <名字> --worker`。
- **每条任务有编号**（任务 1、任务 2…，只属于你自己，只增不减、重启也不清零）。
  - 只有一条任务时：直接回消息就是回它，不用编号。
  - 有多条时：要带编号，比如 `#2 正文`（或 `/reply 2 正文`）。不带编号它会先把任务清单发给你，照着补上编号重发即可；例外是**只有一条正等你回复**时，无编号消息会直接喂给它。
- 看进度发 `任务列表`；不想要了就 `结束任务`（只有恰好一条活跃任务时才是它）、`结束任务 2`（结束 2 号）或 `结束全部任务`——有两条以上在跑时不带编号会被拒，它会先回一份编号清单让你指明。
- 也能在**电脑终端**直接派，还能指定工作目录和用什么大脑：
  ```bash
  wemind task "把这个项目的测试补全" --cwd /path/to/项目 --agent kiro
  wemind task-list       # 看进度（编号 / 大脑 / 状态）
  wemind task-reply 2 "第 2 点不用查"   # 回复 2 号任务（只有一条时可省略编号）
  wemind task-stop       # 结束
  ```
- **最多同时跑 3 条**（想改设 `WEMIND_MAX_WORKERS`）；满了再派会被拒并告诉你。任务跑完（循环结束）进程**留着复用**，空闲 5 分钟自动回收；停在「等你回复」的任务则一直占着那条连接——它不计入空闲进程、也不受 5 分钟回收影响；正在跑的任务被你 `结束任务` 时是**直接杀掉**（ACP 回合没法优雅取消，进程不保留）。
- **daemon 重启后**：没跑完的任务在 `任务列表` 里标着「已中断」，**不会自己跑起来**；你回 `继续`（或 `#2 继续`）它才试着接上原来的进度。接不上会直说「这次接不上」，并告诉你重试也是一样的结果——想重来就结束这条任务后重新派一条（把进展写进新任务）；续跑前也会提醒你「半截回合可能已经做过一些动作，注意核对」。

### 多账号

`wemind login` 多跑几次就能登录多个微信号，各自独立、互不干扰：

```bash
wemind login --label 工作号 --start
wemind login --label 私人号 --start
wemind list           # 查看所有账号
wemind stop 工作号     # 停某个
```

## 常见问题（FAQ）

- **扫码后页面一直加载** → 切到手机流量（关 WiFi）再扫。
- **登录后大脑不回复**（路线二）→ 跑 `wemind brain <账号>` 看解析到的 agent（`wemind brain check` 会真起一次 ACP 握手）；确认它能在终端跑、配了可用模型；看日志 `~/.wemind/<账号>/daemon.log`。环境不确定先跑 `scripts/doctor.ps1`。
- **`wemind` 命令找不到** → 先 `npm i -g @wemind/cli`；不想全局装就用 `npx -y @wemind/cli …`（注意不是 `npx wemind`）；从源码跑则用 `node packages/wechat-daemon/dist/cli.js …`。装完用 `wemind version` 确认。
- **想升级到新版本** → `npm i -g @wemind/cli@latest`，然后 `wemind stop <账号> && wemind start <账号>` 让常驻进程用上新版本（正在运行的 daemon 不会自动换代码）。**升级 CLI 后建议重启一次 daemon**：`brain switch`（换大脑）、`brain switch --worker`（换默认任务大脑）、交接、`session new` / `session resume` 这几条必须由 daemon 执行——daemon 还在跑旧版时，CLI 会在**发出前**拒绝并提示 `wemind stop <账号> && wemind start <账号>`。`session rename` / `delete` 本来就只改文件，照常能用；`session list` 会自动降级成直接读登记表，并附一行说明（按「下次会用的大脑」列）；`task-list` / `task-status` 从不经过控制桥，只有 daemon 没在跑时才会多一行「这是上次留下的记录」。
- **Windows 开机自启没生效** → `pm2 startup` 在 Windows 不原生支持，用任务计划程序跑 `pm2 resurrect`。
- **会话过期 / 一段时间收不到** → iLink 会话超时（约 1 小时冷却），重新发条消息即可恢复。
- **隔一会儿就不回了** → 一轮里 bot 连续发太多条会被限流，回复「继续」即可恢复（长任务常见）。

## 安全须知（务必读）

- **路线二的大脑默认免审批**（内置预设各用自己 agent 的开关，如 kiro 的 `--trust-all-tools`、qoder 的 `--yolo`）：意味着**消息一旦被接受，就能让 AI 在你电脑上执行任意操作（含运行命令、读写文件）**。**微信平台只把发给这个 bot 的消息发送给登录者本人，也就是你**，所以能驱动它的只有你自己；代码里还有一道**登录者白名单**（`allowFrom`，默认拒绝、登录时自动写入）作为**兜底**——万一发送范围变化或 daemon 被接到别的入口，清单外的发件人一律忽略（`daemon.log` 记 `ignore unauthorized sender`）。**不要关掉这道闸**（正常无需手动配置）。
- **口令权限**：`AI` / 换大脑 / 换默认任务大脑 / 交接这四条是**账号级**指令，代码里只有「登录者」（扫码登录这个 bot 的那个微信号）能发，非登录者会被短提示拒绝、不转给大脑——这是**兜底校验**，平台上本来也只有你能发消息；**会话管理与任务指令是「登录者自己的」**，永远只影响你自己的会话与任务。这跟「账号与账号」无关：每个微信号各有自己的 bot 与登录者，**不存在谁能管谁的「主号」**。
- **凭证存储**：登录凭证存在 `~/.wemind/<账号>/account.json`。**Windows 上是明文**，请用文件夹权限或磁盘加密保护。
- **隐私**：消息会经过腾讯 iLink 通道和你本地的 AI 流转，涉及对话内容外发，请自行评估再用。

## 卸载 / 重置

- **停止常驻**：`wemind stop <账号>`（pm2 方式再 `pm2 delete wemind-<key>`）。
- **退出登录**：`wemind logout <账号>`（停服务 + 下线 + 清凭证，保留目录可重登）。
- **彻底删除某账号**：`wemind delete <账号>`（连目录一起删）。
- **重置对话记忆**：更省事的做法是在微信发 `新会话`（只开一条新的，旧的还能用 `会话列表` / `恢复会话` 找回来）；要彻底清空，删 `~/.wemind/<账号>/brain-sessions.json`（当前会话当前会话记录）与 `session-registry.json`（会话列表），以及 `brain-home/sessions/`。
